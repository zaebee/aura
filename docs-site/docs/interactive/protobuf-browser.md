# Protobuf Browser

:::info Coming Soon
This interactive component will provide a visual browser for all Protobuf types in the DNA schema.
:::

## Planned Features

- Collapsible tree of all message types
- Click to expand field details
- Highlight `oneof` discriminated unions
- Show enum values and comments
- Link to `.proto` source files

## Preview

Browse types like:
- `Signal` → `Context` + `Intent`
- `Intent` → action + params
- `Observation` → result + metadata
- `Event` → type + payload

All types will be clickable with full documentation.
