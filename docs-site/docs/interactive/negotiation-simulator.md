# Negotiation Simulator

:::info Coming Soon
This interactive component will let you step through the complete negotiation metabolism flow.
:::

## Planned Features

- Input fields: bid amount, item ID, floor price
- "Next Step" button to advance through ATCG-M
- Visual highlighting of current nucleotide
- Decision tree branches
- Membrane override visualization

## Preview

The simulator will show:

1. **M(in)**: Validate bid against floor price
2. **A**: Aggregated context (item, user, history)
3. **T**: Decision outcome (accept/counter/reject)
4. **M(out)**: Output validation
5. **C**: Response routing
6. **G**: Events emitted

Try different bid amounts to see how the metabolism responds!
