# Protocol Explorer

:::info Coming Soon
This interactive component will allow you to explore ATCG-M protocol implementations across all Proteins in the Hive.
:::

## Planned Features

- Browse proteins by nucleotide (A/T/C/G/M)
- View protocol signatures and types
- Link to source code on GitHub
- Show which Skills each protein calls

## Preview

The Protocol Explorer will load data from `arch_brain.json` and display:

1. **Protein Map**: Visual grid of all proteins
2. **Protocol Browser**: Click a nucleotide to see implementations
3. **Type Explorer**: Hover to see Protobuf types
4. **Source Links**: Direct links to GitHub code

Check back soon for the full interactive experience!
